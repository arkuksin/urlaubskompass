# Urlaubskompass

Ein heller, geführter Familien-Ausflugsplaner für sieben Urlaubsideen rund um Troyes, den Lac d’Orient, die Champagne und Namur.

Die Auswahl führt in drei Schritten durch Tageslage, Stimmung und gewünschten Tagesrahmen. Anschließend werden die am besten passenden Ideen mit Ablauf, Packliste und aktuellen Hinweisen gezeigt. Favoriten bleiben lokal im Browser gespeichert.

## Lokal starten

Voraussetzung ist Node.js 22 oder neuer.

```bash
npm install
npm run dev
```

Der Produktions-Build wird mit `npm run build` erstellt.
